Docker — Build & Check

Các câu lệnh chính cho TravelHub trên Ubuntu WSL2 / Docker Compose. Mở file HTML này bằng Chrome hoặc Edge, không cần Internet để xem. Nhấn Sao chép để lấy lệnh.

0. Vào thư mục dự án

cd /mnt/c/Users/Khanh/Desktop/ANY/travelhub-copilot-docs

Mở Ubuntu WSL, sau đó chạy các lệnh bên dưới tại thư mục này. Cần có .env hợp lệ và Docker đang hoạt động.

LOCAL — LẬP TRÌNH

1. Build & chạy Local

Chạy Vue User/Admin bằng Vite dev server và FastAPI để phát triển trên máy.

Build + Start + Check

docker compose up -d --build
docker compose ps
curl -i http://127.0.0.1:8000/health
Ứng dụngĐịa chỉ mở trên máy PC
Website Userhttp://localhost:5173
Website Adminhttp://localhost:5174
Backendhttp://localhost:8000/health

Các địa chỉ localhost chỉ dùng trên chính máy chạy Docker, không tự truy cập được qua 4G.

PUBLIC — DEMO TỪ THIẾT BỊ KHÁC

2. Build & kiểm tra bản Public

Build Vue User/Admin thành file tĩnh phục vụ qua Nginx, API đi qua cùng origin. Không mở Vite dev server ra Internet.

Trước khi chuyển sang cấu hình Public, sao lưu PostgreSQL, kiểm tra JWT_SECRET_KEY đủ mạnh và chỉ dùng dữ liệu demo. Compose Public có thể khởi động lại backend.

Validate cấu hình

docker compose -f docker-compose.yml -f docker-compose.pc-tunnel.yml config --quiet

Build + Start + Check

docker compose -f docker-compose.yml -f docker-compose.pc-tunnel.yml up -d --build backend public-web admin-web
docker compose -f docker-compose.yml -f docker-compose.pc-tunnel.yml ps

Kiểm tra User HTML

docker compose -f docker-compose.yml -f docker-compose.pc-tunnel.yml exec public-web wget -qO- http://127.0.0.1:8080/ | head -c 200

Kiểm tra Admin HTML

docker compose -f docker-compose.yml -f docker-compose.pc-tunnel.yml exec admin-web wget -qO- http://127.0.0.1:8081/ | head -c 200

Kiểm tra API qua Nginx

docker compose -f docker-compose.yml -f docker-compose.pc-tunnel.yml exec public-web wget -qO- http://127.0.0.1:8080/api/v1/tours | head -c 300
Kết quả mong đợi: hai trang HTML có <!doctype html>, API trả JSON chứa "items". Đây mới là build/check nội bộ, chưa có URL công khai.
CLOUDFLARE — HTTPS + OTP

3. Truy cập Public trên điện thoại / laptop khác

Sau khi bước 2 thành công, mở hai terminal Ubuntu riêng và chạy Quick Tunnel. Cloudflare cấp hai URL ngẫu nhiên *.trycloudflare.com, không cần mua domain.

Terminal A — Website User

docker compose -f docker-compose.yml -f docker-compose.pc-tunnel.yml run --rm --no-deps -e TUNNEL_TOKEN= cloudflared tunnel --url http://public-web:8080 --allowed-mail nguyenquockhanh16032k@gmail.com

Terminal B — Website Admin

docker compose -f docker-compose.yml -f docker-compose.pc-tunnel.yml run --rm --no-deps -e TUNNEL_TOKEN= cloudflared tunnel --url http://admin-web:8081 --allowed-mail nguyenquockhanh16032k@gmail.com
BẮT BUỘC xác minh trang yêu cầu OTP với email được phép trước khi chia sẻ URL. Nếu --allowed-mail không được hỗ trợ hoặc trang mở ngay không cần OTP, nhấn Ctrl + C để dừng Tunnel; không bỏ lớp bảo vệ để public Admin. OTP Cloudflare không tự cấp role SUPER_ADMIN trong TravelHub.

Trên điện thoại, tắt Wi-Fi, mở URL do terminal in ra bằng 4G/5G để thử. Giữ PC, Docker và terminal đang chạy. URL có thể thay đổi sau mỗi lần tạo Tunnel.

4. Khi lỗi / cần dừng

Xem log

docker compose -f docker-compose.yml -f docker-compose.pc-tunnel.yml logs --tail=80 backend public-web admin-web

Dừng web Public (không xóa database)

docker compose -f docker-compose.yml -f docker-compose.pc-tunnel.yml stop public-web admin-web

Dừng Quick Tunnel bằng Ctrl + C tại từng terminal. Không chạy docker compose down -v vì có thể xóa volume PostgreSQL.
